# DUVAN CORE — GitHub Profile Setup

## 1. Crear el repositorio especial

En GitHub crea un repositorio con el mismo nombre exacto de tu usuario.

Ejemplo:

```txt
TU_USUARIO_GITHUB/TU_USUARIO_GITHUB
```

GitHub mostrará automáticamente el `README.md` de ese repositorio como tu perfil.

## 2. Subir archivos

Sube esta estructura completa:

```txt
TU_USUARIO_GITHUB/
│
├── README.md
│
├── SETUP.md
│
├── assets/
│   ├── banner.svg
│   ├── divider.svg
│   ├── glyph-core.svg
│   ├── dot-icons.svg
│   ├── footer.svg
│   ├── project-queue-core.svg
│   ├── project-sap-flow.svg
│   ├── project-ad-manager.svg
│   └── project-kiosk.svg
│
└── prompts/
    ├── banner-prompt.txt
    └── dot-icons-prompt.txt
```

## 3. Reemplazar placeholders

Busca y reemplaza:

```txt
TU_USUARIO_GITHUB
TU_LINKEDIN
TU_CORREO
TU_PORTAFOLIO.com
```

## 4. Cambiar enlaces de proyectos

En el README hay enlaces así:

```html
<a href="#">
```

Reemplaza `#` por los enlaces reales a tus repositorios.

## 5. Personalización recomendada

- Mantén el fondo oscuro en los SVG.
- Usa pocos colores.
- Usa `#20A7FF` solo como acento.
- No uses demasiados GIFs porque hacen lento el perfil.
- Para mantener la estética premium, usa banners SVG en lugar de imágenes pesadas.
